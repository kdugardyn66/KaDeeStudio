# Welcome to KadeeStudio

KadeeStudio is a native Rust office suite for Markdown, PDF, conversion,
dashboards and reports — with real-time collaboration through a
self-hosted server (Docker or Kubernetes).

## What works today

- **Kadee Markdown** (this editor): a word processor for Markdown with a ribbon,
  live preview, slides, a slide show (F5), templates under **File › New** and
  your own templates under **My templates**, export to PDF and web pages
- **KaDee AI**: the ✦ button (Cmd/Ctrl+J) opens the assistant next to this
  document; it reads what you write and **Insert into document** puts its
  answer at the cursor
- The start screen: quick-start cards, Recent, Starred and your documents folder
- New Markdown, Dashboard and Report files are created in `~/Documents/KadeeStudio`
- **All** lists every file KadeeStudio or a Crafting App opens: Office, graphics, audio, video and CAD files too
- Light, dark and system themes
